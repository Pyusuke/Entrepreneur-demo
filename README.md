# 探究振り返りカードゲーム

高校生向けワークショップ「探究振り返りカードゲーム」のWebアプリです。
アントレプレナーシップ教育のお試し授業（120分）の中核となる65分ワークショップを支援します。

**設計原則：「ルールは薄く、対話は厚く、所作は残す」**

- 勝敗・点数・数値パラメータはありません。判定は班の対話が行います（アプリは判定しません）
- カードの「作る・並べる・切る・裏返す」という所作をUIで再現します
- 生徒に持ち帰らせたい体験：「派手な成果がなくても、自分のプロセスと能力は手札として通用する」

## 使い方

**ビルド不要**。`index.html`・`sw.js`・`html2canvas.min.js`（画像保存用・ローカル同梱）の3ファイル構成です。

- 配布：Vercel / GitHub Pages / 校内サーバーなどにそのまま置いてURLを開く（`index.html` 単体をコピーしてダブルクリックで開いても動きますが、その場合オフラインキャッシュは効きません）
- HTTP(S)で開いた場合、Service Worker（`sw.js`）が初回アクセス時にキャッシュを作り、**以降はオフラインでもリロード・動作できます**。外部リソースは一切読み込みません
- データはすべてブラウザの `localStorage` に保存されます。送信機能はなく、ニックネーム以外の個人情報は扱いません
- リロードしても途中経過は復元されます

### デプロイ時の注意

`index.html` を更新したら、`sw.js` 冒頭の `CACHE_VERSION` を上げてください（例 `"v2"` → `"v3"`）。これで各端末のキャッシュが次回ロード時に新しいファイルへ更新されます。

## 画面遷移パスワード

生徒が勝手に先へ進んでお題を見てしまわないよう、「次へ」にはパスワードがかかっています。ファシリテーターが各パートの開始時に口頭で伝えてください（「もどる」方向と、一度通過した遷移は入力不要）。

| 遷移 | パスワード |
|---|---|
| スタート → ①棚卸し | なし |
| ①棚卸し → ②眺める | `12345` |
| ②眺める → ③お題1 | `5555` |
| ③お題1 → ④お題2 | `0120` |
| ④お題2 → まとめ | `999` |

変更する場合は `index.html` 冒頭の `PASSWORDS` 定数を書き換えてください。

## 画面フロー（5画面＋まとめ）

| 画面 | 内容 | 想定時間 |
|---|---|---|
| スタート | ニックネーム入力 | ─ |
| STEP1 棚卸し | 5カテゴリーを素材にカードを作る（成果・プロセス・能力 各1枚以上、計5枚まで。不足分は余白カードに） | 25分 |
| STEP2 手札を眺める | 手札一覧・並べ替え・気づきメモ | 10分 |
| STEP3 お題1「大学生、何する？」 | メニュー7項目から2つ選択、未来カード発行（1〜2枚・点線枠・種別必須） | 15分 |
| STEP4 お題2「思ってたのと違った、どうする？」 | 未来カードが裏返る演出 →「次は何を目指す？」で未来カードを1枚再発行 → 手札と余白で向かう。余白を切るときは獲得宣言（未来形）が必須 | 15分 |
| まとめ | 手札と回答の一覧。「📷 画像で保存」でPNGをダウンロード（`たんきゅうカード_{ニックネーム}_{日付}.png`）、印刷にも対応 | ─ |

画面遷移は生徒の手動操作です（ファシリテーターの合図で各自進む運用）。

## カードの種類

| 種別 | 色 | 記入ルール |
|---|---|---|
| 成果 | 青 | 名詞で書く（できたこと・生まれたもの） |
| プロセス | 緑 | 動詞で書く（〜した、〜し続けた） |
| 能力 | 橙 | 力の名前＋出典（どのカードから得たか必須） |
| 余白 | 白・点線枠 | 白紙のまま持つ。新しく獲りに行く宣言として切れる枠 |
| 未来 | 紫の点線枠＋種別色のバンド | 将来の成果/プロセス/能力のどれかを選んで発行。お題1発行分はSTEP4開始時に裏返り、お題2で1枚「目指し直し」として再発行する |

## 先生用機能

各画面右上の「⚙ 設定」から：

- **データリセット**：端末を使い回すときにデータを消去（復元不可の確認あり）
- **JSONエクスポート／インポート**：授業前のバックアップ・テストプレイのデータ回収用。実行には運営用パスワード `13579` が必要です（`index.html` の `ADMIN_PASSWORD` 定数で変更可）。インポートは形式検証つきで、不正なファイルは現在のデータを変更しません
- **テストデータ読み込み**：4ペルソナ（ミナ・ケンタ・アオイ・ユウ）。STEP3の回答・お題2の目指し直し未来カード・STEP4の回答までプリセット済みで、まとめ画面まで通しで確認できます（読み込み時に上書き確認あり）

## 技術構成

- 依存ライブラリなしの HTML + CSS + Vanilla JS（`index.html`）＋ オフライン用 Service Worker（`sw.js`）
- サーバー・DB・ログイン・通信機能なし
- スマホ（縦）・タブレット（横）対応のレスポンシブ
- 班同士のデータ共有機能はスコープ外（共有は口頭と画面の見せ合いで行います）

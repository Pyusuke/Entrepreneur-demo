# 探究振り返りカードゲーム

高校生向けワークショップ「探究振り返りカードゲーム」のWebアプリです。
アントレプレナーシップ教育のお試し授業（120分）の中核となる65分ワークショップを支援します。

**設計原則：「ルールは薄く、対話は厚く、所作は残す」**

- 勝敗・点数・数値パラメータはありません。判定は班の対話が行います（アプリは判定しません）
- カードの「作る・並べる・切る・裏返す」という所作をUIで再現します
- 生徒に持ち帰らせたい体験：「派手な成果がなくても、自分のプロセスと能力は手札として通用する」

## 使い方

**ビルド不要・サーバー不要**。`index.html` をブラウザで開くだけで動きます。

- 端末への配布：`index.html` を各端末にコピーしてダブルクリックで開く、または校内サーバー/GitHub Pages などに置いてURLを開く
- 初回ロード後はオフラインで動作します（外部リソースを一切読み込みません）
- データはすべてブラウザの `localStorage` に保存されます。送信機能はなく、ニックネーム以外の個人情報は扱いません
- リロードしても途中経過は復元されます

## 画面フロー（5画面＋まとめ）

| 画面 | 内容 | 想定時間 |
|---|---|---|
| スタート | ニックネーム入力 | ─ |
| STEP1 棚卸し | 5カテゴリーを素材にカードを作る（成果・プロセス・能力 各1枚以上、計5枚まで。不足分は余白カードに） | 25分 |
| STEP2 手札を眺める | 手札一覧・並べ替え・気づきメモ | 10分 |
| STEP3 お題1「大学生、何する？」 | メニュー7項目から2つ選択、未来カード発行（1〜2枚・点線枠） | 15分 |
| STEP4 お題2「思ってたのと違った、どうする？」 | 未来カードが裏返る演出 → 手札と余白で解く。余白を切るときは獲得宣言（未来形）が必須 | 15分 |
| まとめ | 手札と回答の一覧。印刷・スクリーンショット用レイアウト | ─ |

画面遷移は生徒の手動操作です（ファシリテーターの合図で各自進む運用）。

## カードの種類

| 種別 | 色 | 記入ルール |
|---|---|---|
| 成果 | 青 | 名詞で書く（できたこと・生まれたもの） |
| プロセス | 緑 | 動詞で書く（〜した、〜し続けた） |
| 能力 | 橙 | 力の名前＋出典（どのカードから得たか必須） |
| 余白 | 白・点線枠 | 白紙のまま持つ。新しく獲りに行く宣言として切れる枠 |
| 未来 | 紫・点線枠 | STEP3で生徒が発行。STEP4開始時に裏返る |

## 先生用機能

各画面右上の「⚙ 設定」から：

- **全データリセット**：端末を使い回すときにデータを消去
- **テストデータ読み込み**：4ペルソナ（ミナ・ケンタ・アオイ・ユウ）で通し動作を確認できます

## 技術構成

- 依存ライブラリなしの単一HTMLファイル（HTML + CSS + Vanilla JS）
- サーバー・DB・ログイン・通信機能なし
- スマホ（縦）・タブレット（横）対応のレスポンシブ
- 班同士のデータ共有機能はスコープ外（共有は口頭と画面の見せ合いで行います）
